# 📊 Telecom Customer Churn Analysis

### End-to-End Data Analytics Project using Python, SQL & Power BI

---

## 📌 Project Overview

Customer churn is one of the major challenges faced by telecom companies. This project analyzes **7,043 telecom customer records** to understand why customers leave, identify high-risk customer segments, and generate actionable customer-retention strategies.

The project follows a complete data analytics workflow:

**Python → SQL → Power BI → Business Insights → Retention Recommendations**

---

## 🎯 Business Objective

The main goal of this project is to understand customer churn and answer important business questions such as:

- What is the overall churn rate?
- Which contract type has the highest churn?
- How does customer tenure affect churn?
- Which payment method is associated with higher churn?
- Which internet service has the highest churn?
- Which customer segment is at the highest risk?
- Are high-value customers also churning?
- What strategies can help improve customer retention?

---

## 📂 Dataset

The project uses the **IBM Telco Customer Churn Dataset**.

### Dataset Summary

| Metric | Value |
|---|---:|
| Total Customers | 7,043 |
| Total Attributes | 21 |
| Churned Customers | 1,869 |
| Retained Customers | 5,174 |
| Overall Churn Rate | 26.54% |

The dataset includes customer information related to:

- Demographics
- Tenure
- Contract type
- Payment method
- Monthly & total charges
- Internet service
- Phone services
- Online security
- Technical support
- Streaming services
- Customer churn
